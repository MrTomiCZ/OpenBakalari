# OpenBakaláři
> [!IMPORTANT]
> Program je ještě ve vývoji.

Open Source Bakaláři server řešení. Funguje s mobilní aplikací.
Pro použití na PC můžete použít [BakalariCLI](https://github.com/schizza/async-bakalari-api3)

# Instalace
## Pro Linux
Požadavky:
- Node.js
- git
```bash
git clone https://github.com/MrTomiCZ/OpenBakalari openbk
cd openbk/src
npm i
```
Poté spuštění:
```bash
npm run prod
```
